# 🟢 Othello Online (WebRTC P2P)

URLを送るだけで誰とでもすぐに遊べる、完全ゼロサーバー設計のオンラインオセロ（リバーシ）です。

## 特徴
- **インストール・ポート開放一切不要**: WebRTC (STUN / NAT越え) 技術により、ブラウザだけで直結通信。
- **URL共有ワンクリック対戦**: 部屋を作って発行されたURLをチャットで送るだけ。友達が開いた瞬間に自動合流して対戦がスタート。
- **正確なオセロルール**: 置ける場所のガイド表示、自動挟み込み反転、パス判定、勝敗判定を完備。
- **軽量・ゼロサーバー**: PeerJSの無料クラウドを利用するため、サーバーの契約や運用が一切不要。

## 公開方法
1. [Netlify Drop](https://app.netlify.com/drop) を開く
2. 本フォルダをそのままドラッグ＆ドロップするだけで、数秒で世界中から遊べるURLが手に入ります。
